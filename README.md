# Kraft K14

[**Jogar ou instalar no navegador**](https://kadkok.github.io/kraft-cliente/) · [**Baixar para Windows e Linux**](https://github.com/kadkok/kraft-cliente/releases/latest/download/Kraft-PC.zip) · [**Multiplayer**](https://kraft.k14.uk/?partida=multiplayer)

O site oferece **Baixar para jogar offline**. Aguarde **Pronto para jogar offline**. No iPhone ou iPad, use **Compartilhar → Adicionar à Tela de Início** no Safari.

Para jogar no PC, extraia todo o ZIP e abra **Kraft.exe** no Windows x64 ou **Kraft-Linux** no Linux x64. A primeira partida solo já funciona sem internet. O mundo solo fica no navegador e aparelho em que você joga.

As atualizações do pacote estão na [página de versões](https://github.com/kadkok/kraft-cliente/releases).
